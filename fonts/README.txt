Self-hosted web fonts
=====================

These fonts are used as a free, brand-matching stand-in for the main site's
commercial "Circe" typeface.

Nunito Sans  (body text)   — © The Nunito Sans Project Authors
Zilla Slab   (headings)    — © The Mozilla Foundation

Both are licensed under the SIL Open Font License, Version 1.1 — free for
commercial use, including self-hosting and embedding.
License text: https://openfontlicense.org

Source: Google Fonts (https://fonts.google.com), Latin + Latin-Extended subsets.
Other scripts (Hebrew, Arabic, Cyrillic, CJK, etc.) fall back to the system font.

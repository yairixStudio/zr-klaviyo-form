Embed Example

This is how the signup form looks embedded as an <iframe> on another site. The iframe below auto-resizes to its content height via postMessage.

The iframe src is built dynamically below: it forwards this page's URL params into the form. Try adding ?city=paris&country=israel&channel=qrcode to this page's URL and reload — the form will reflect it.

Paste-ready snippet (forwards the page's URL params)

<iframe id="zr-form"
  style="width:100%;max-width:680px;height:560px;border:0;"
  title="Sign up — Zielinski & Rozen" loading="lazy"></iframe>

<script>
  (function () {
    var base = 'https://yairixstudio.github.io/zr-klaviyo-form/';
    var iframe = document.getElementById('zr-form');
    // Forward THIS page's URL params (?city=&country=&channel=...) into the form.
    iframe.src = base + window.location.search;
    // Auto-resize the iframe to the form's height.
    window.addEventListener('message', function (e) {
      if (e.data && e.data.type === 'zr-klaviyo-form:height') {
        iframe.style.height = e.data.height + 'px';
      }
    });
  })();
</script>

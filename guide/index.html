Signup Form — Guide

A standalone, multilingual newsletter signup form for Zielinski & Rozen. It submits directly to Klaviyo and can be shared as a link, printed as a QR code, or embedded on any website as an <iframe>.

The three tools

  • The form — the live signup form. This is what visitors fill in.
  • QR generator — build a campaign link and download a QR code for print, ads, or in-store.
  • This guide — how it works, URL parameters, and ready-to-paste embed code.

How submission works

The form posts directly to Klaviyo's Client Subscriptions API. Authentication is a public company ID only (no secret key), and the endpoint is CORS-enabled — so the form works from any origin, including inside an iframe on a third-party site. Consent links to the Privacy Policy.

Languages

The interface is available in 11 languages — English, Arabic, Chinese, French, German, Hebrew, Hindi, Italian, Portuguese, Russian, and Spanish — with a switcher at the bottom of the form. The starting language is chosen automatically: ?lang= in the URL, then a saved choice, then the browser language, then the visitor's country, then their IP/timezone — falling back to English.

URL parameters

Any of these can be added to the form URL (or the iframe src). They prefill fields and attach as profile properties.

ParameterPurpose
cityPrefills the City field
countryPrefills Country — ISO code (FR) or name (France)
channel / sourceMarketing channel (default qr-code)
store_id / storeOriginating store / location
qr_id / qr / codeSpecific QR / campaign code
langForce a starting language, e.g. fr, es, ar
utm_*Standard UTM tags, stored as-is
debug=1Shows the outgoing payload (for testing)

Embed as an iframe

A cross-origin iframe cannot read the host page's URL, so to forward the host page's parameters into the form, the host sets the iframe src with one small script. This also auto-resizes the iframe to the form's height.
